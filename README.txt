BLOOMMARK — WEBSITE DEMO

Cách xem trên máy tính:
1. Giải nén bloommark_website.zip.
2. Mở thư mục bloommark_website.
3. Nhấp đúp vào index.html để mở trong Chrome.

Cách đưa lên Vercel:
1. Tạo tài khoản GitHub và Vercel.
2. Tạo repository GitHub mới tên bloommark.
3. Tải lên index.html, style.css, script.js và README.txt (có thể kéo thả tệp trên trang repository).
4. Trên Vercel chọn Add New -> Project, nhập repository bloommark.
5. Nếu hỏi framework, chọn Other; Build Command để trống; Output Directory để trống hoặc ./ nếu giao diện yêu cầu.
6. Nhấn Deploy. Khi hoàn tất, Vercel hiển thị link .vercel.app.

Lưu ý:
- Đây là website tĩnh demo; đơn hàng chưa được lưu vào cơ sở dữ liệu và chưa có thanh toán trực tuyến.
- Giá là giá tham khảo, hãy chỉnh lại trước khi công khai.
- Hình ảnh từ Unsplash dùng để minh họa, không phải ảnh sản phẩm resin thật của shop.
- Cập nhật đường dẫn mạng xã hội và thông tin liên hệ trước khi chia sẻ.
